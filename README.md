# DOE_APP
App web interactiva en Streamlit para analizar diseños factoriales 2^k (DOE). Alternativa educativa a Minitab.

# DOE 2^k — Analizador tipo Minitab

Aplicación web interactiva desarrollada en Python y Streamlit para el análisis de **Diseños de Experimentos (DOE) Factoriales 2^k**. 

Esta herramienta sirve como una alternativa educativa a Minitab, guiando al estudiante a través del flujo de trabajo estadístico.

## Características

- Soporte para 3 tipos de diseños:
  - **Vía 1**: Réplicas puras.
  - **Vía 2**: Bloques con punto central.
  - **Vía 3**: No replicado (método de Lenth).
- Generación automática de ANOVA, Diagramas de Pareto, Gráficos Semi-normales y Diagnóstico de Residuales.
- Flujo interactivo tipo Minitab: permite seleccionar manualmente los términos significativos para refinar el modelo.
- Exportación de resultados a Excel, plantilla de Word y gráficos en PNG.

## Cómo usar

1. Sube un archivo Excel o CSV con tus datos.
2. Selecciona las columnas correspondientes a los factores y la respuesta.
3. Elige la vía de análisis según el diseño de tu experimento.
4. Sigue los pasos en pantalla para interpretar los resultados y generar el reporte final.
